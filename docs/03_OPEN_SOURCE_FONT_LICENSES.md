# 📜 Open Source Typography Licensing Matrix

A legal comparison of font licenses to ensure your projects remain 100% legally compliant for commercial websites, mobile apps, and enterprise software.

---

| License | Commercial Use | Embedding in Web/Apps | Modifying Contours | Selling the Font by Itself | Renaming Font |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **SIL OFL 1.1** | ✅ Yes | ✅ Yes | ✅ Yes | ❌ No | ⚠️ Requires Reserved Font Name change |
| **Apache 2.0** | ✅ Yes | ✅ Yes | ✅ Yes | ❌ No | ✅ Allowed with notices |
| **MIT License** | ✅ Yes | ✅ Yes | ✅ Yes | ❌ No | ✅ Allowed |
| **CC0 (Public Domain)** | ✅ Yes | ✅ Yes | ✅ Yes | ✅ Yes | ✅ Allowed |

---

### SIL Open Font License 1.1 Key Clause:
> *"Neither the Font Software nor any of its individual components, in Original or Modified Versions, may be sold by itself."*

This guarantees that open-source fonts forever remain free for the global design community.
